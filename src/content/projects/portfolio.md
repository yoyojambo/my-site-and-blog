### Project Overview
This website serves as both my digital business card and a playground for experimenting with modern web technologies. I built it with **Astro** to ensure maximum performance and a minimal JS footprint.

### Design Philosophy
- **Dark Mode First**: Optimized for long reading sessions with a custom "Doom One" inspired color palette.
- **Simplicity**: No heavy frameworks where not needed—just clean HTML, CSS, and minimal TypeScript.
- **Content-Driven**: Using Astro's Content Layer to manage projects and blog posts efficiently.
